　商品采购图册　v1.0
　点图即达 · 本地运行 · 不需要联网
════════════════════════════════════════


【 怎么打开 】
　双击同目录下的「采购图册.exe」


【 第一次用，按这四步走 】
　1. 点左上角白色的「＋」按钮

　2. 选「图片文件夹」，把放商品图的整个文件夹选进来
　　 程序会自动复制图片、生成缩略图、给每张图建一条记录
　　 1000 张也可以，上方会显示进度条

　3. 图都进来后，点「导出当前清单」，得到一个 Excel
　　 用 Excel / WPS 打开，填这三列：
　　 　商品名称、采购链接、分类
　　 （货号、备注可选填）

　4. 填好后点「导入表格」，把这个 Excel 选进来
　　 程序会按「图片文件名」自动把数据和图片对上

　完成后回到主界面，鼠标移到图片上会浮出商品名和货号，
　点一下就直接打开采购链接。


【 平时怎么加新货 】
　· 有新图片 → 点「＋」→ 选择图片 / 图片文件夹
　· 只有图片没有链接 → 先导进来，之后在卡片上点右键 → 编辑
　· 从网页看到喜欢的图 → 右键「复制图片地址」→ 点「＋」→ 粘贴图片链接
　· 想改某一件 → 在卡片上点右键 → 编辑


【 数据存在哪 】
　就在这个文件夹里：

　　采购图册.exe
　　data\
　　　items.json　　← 所有商品名称和链接
　　　images\　　　 ← 你的原图
　　　thumbs\　　　 ← 缩略图（程序自动生成，别手动改）

　★ 备份方法：把整个「data」文件夹复制一份存起来
　★ 换电脑：把整个程序文件夹拷过去，data 一起带走


【 几个要注意的 】
　1. 别放在 C:\Program Files 里，那里可能没权限写数据
　2. 建议放 D 盘，或者桌面上
　3. 第一次双击如果弹出「Windows 已保护你的电脑」：
　　 点「更多信息」→「仍要运行」
　4. 如果杀毒软件拦截：选「允许」或加入信任列表
　　 （这个程序没买数字签名，属于正常现象）


【 快捷键 】
　Ctrl + K　→　跳到搜索框
　Esc　　　 →　关闭面板 / 清空搜索


【 出问题了怎么办 】
　· 图片不显示 → 关掉重开程序；还不行就检查 data\images 里有没有文件
　· 导入很慢 → 正常，图片多的时候要看进度条，别中途关窗
　· 数据错了想重来 → 「＋」→ 最下面「清空全部数据」
　　 （清空前记得先「导出当前清单」备份）
