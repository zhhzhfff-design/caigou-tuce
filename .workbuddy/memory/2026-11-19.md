## 采购图册 v1.6（Electron 桌面程序）

用户实测反馈六问题，全部修复：

1. **表格导入带链接不下载图** —— 根因：`applyTable` 只把 url 写进字段，从不触发下载（单独粘链接走的是 `import-urls`，所以能成）。新增 `fetchMissingImages()`，导入后并发 3 路调 `download-one`，带进度条 + 失败明细面板。
2. **并发下载随机丢结果** —— 根因：多个 `download-one` 同时 read-modify-write `items.json`，后写的覆盖前一个。加 `withDbLock()` 写锁：下载并发、写记录串行。
3. **滚动卡顿** —— 根因：`.thumb::before` 骨架屏跑 `background-position` 动画，100+ 张同时重绘。改 `opacity` 呼吸（合成层）+ 卡片 `content-visibility:auto` + `contain-intrinsic-size`；PAGE 60→40，rootMargin 700→500，入场延迟封顶 120ms。实测 6.4ms/帧。
4. **删除后视角跳走** —— 根因：删完 `reload()` 全量重建，DOM 清空时 scrollTop 被浏览器钳制。改 `dropFromView()` 就地摘节点 + 同步状态，不动 scrollTop。`syncPicks()` 替代全选/反选的 `resetRender()`。
5. **滑块太小** —— 轨道 2→5px，滑块 11→17px，宽度 80→120。
6. **1688 / 乐华梅兰链接失败** —— 三层原因：
   - Accept 头带了 `image/avif`，CDN 返 avif 就存不了 → 去掉
   - Referer 单一 → 按站点分派 `siteReferer()`（乐华法/西/意、ManoMano、1688、亚马逊）
   - 商品页 ≠ 图片 → 新增 HTML 提图 `extractPageImage()`（og:image / JSON 字段 / CDN 直链）

### 实测结论（重要，别再重复试）
- `detail.1688.com/offer/*.html` → 200 但只有 2909 字节反爬拦截页，提不到图
- `www.leroymerlin.fr` 整站 403（Akamai），图片 CDN 503
- `cbu01.alicdn.com` 图片直链能下；404 时返 49 字节占位 gif
- unsplash 等普通图床一次成功 → 下载链路本身没问题

### 对付反爬的方案
新增 **Ctrl+V 粘贴图片**（`add-image-buffer` IPC）：截图或右键「复制图片」，回程序直接粘；编辑面板开着则替换当前商品图。已实测通过。

### 校验加强
`validateImageBuf()`：<1KB 或 <80×80 一律拒收（防 1688/淘宝 49 字节占位 gif）。

## 采购图册 v1.7（同日晚，用户第二轮实测反馈）

三个诉求：看图导出（要真图+图片链接）、右侧滚动条加大、1688/乐华链接。

### 关键发现：乐华（ADEO）图片真能下
- 用户表 `1688链接(1).xlsx` 的「照片」列混装两种：前半段 `=DISPIMG()` 嵌入图，后半段是 `https://media.adeo.com/mkp/xxx/media.jpg?width=650...` 直链
- `media.adeo.com` **无防盗链**，200 直接返回；之前失败是因为填了商品页
- 但返回 **WebP**（因为 Accept 头带了 image/webp），而 Electron `nativeImage` 解不了 webp

### 修复清单
- **Accept 头去掉 `image/webp`** → 服务器改返 jpg，问题根除。这是"下载成功却显示不出来"的真凶
- webp 兜底：仍返 webp 时放行存盘（浏览器能显示），只是不做缩略图
- 「照片」列支持直接填图片 URL（原来只认 DISPIMG），判 URL 时排除 `/offer/`、`/produits/`、`.html`
- **导出「含图片」**：选目录 → `采购清单_日期/清单.xlsx` + `images/`。Excel 列：本地图片 / 图片链接 / 商品名 / 1688链接 / 分类 / 货号 / 售价 / 成本 / 重量 / 备注，加第二页「导出说明」
- `download-one`、`import-urls` 都记 `imgUrl`，导出时带上
- **滚动条**（用户指的是右侧竖向滚动条，不是卡片尺寸滑块）：10→18px，滑块可见 4→10px，轨道加淡底，按主题给 `--sb`/`--sb-h` 专色
- 名称清洗：过滤「3个起批」「包邮」，以及 WPS 塞进图片 descr 的 `ex_xxx.jpeg`
- 去重改「链接+图片」组合键（`url||img`）：单纯按 url 会把同一 1688 链接下的多个商品吞掉（122 行导成 114 条）

### 踩坑
- `scrollbar-width: thin` 会被 Chromium 识别并**覆盖** `::-webkit-scrollbar{width}`，导致设 18px 实测只有 10px。删掉标准属性，只用 webkit 伪元素
- preload 的 `exportPack: items => invoke(..., items)` 少传第二个参数，导致 opts 丢失、仍弹原生对话框卡死
- `git add -A` 把 `_test_export/`（12MB）和一堆调试截图提交了。已在 `.gitignore` 加 `_test_export/` 和 `_*.png`，用 amend 重整（未推送前）
- `rm -f xxx.asar` 会被安全策略拦（trash 失败）→ 改输出到新文件名

### 真表实跑结果（1688链接(1).xlsx，122 行）
- 导入 122 条：117 有图、117 有名、122 有价/成本/重量、122 有 1688 链接
- 5 条无图 = 表里本来没图、只有商品页链接（反爬拦）
- 重复导入同一份表 122→122，不产生重复
- 导出 117 张图 10.8MB，清单 86KB
